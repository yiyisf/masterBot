# Isolate Workspace Runs from the host filesystem

A Run that operates on Workspace Files executes in an isolated Sandbox with exactly one fixed Workspace working root, a read-only runtime, and Invocation-private temporary storage; host paths remain invisible, symbolic-link escape is rejected, and external network and credentials are available only through governed capabilities. Observe mounts Workspace content read-only; a mutating Run writes only to an ephemeral overlay that is finalized as an immutable Workspace Change Set, and shared authoritative files change only through the centralized apply transition after confirmation or policy-bounded automatic approval. We reject host execution with path-prefix checks, direct shared-root mutation, and split file/Shell isolation because subprocesses, links, hooks, mounts, concurrent Runs, and recovery would otherwise bypass the Workspace authority boundary or the single write path.
