# Adopt Agent Skills as the preferred external Skill format

CMaster Bot will import and author Skills using the industry Agent Skills `SKILL.md` package shape with progressive disclosure across the manifest body, references, assets, and controlled scripts, then normalize packages into an internal Skill descriptor. Tool contracts and execution remain owned by Tool Providers rather than Markdown action headings; Skill requirements reference stable Tool identities, CMaster-specific metadata stays in a namespaced extension, and bundled scripts receive no automatic execution authority. A Legacy Skill adapter will migrate the current custom frontmatter, `### action_name`, and `index.ts/js` packages into separate Skill and Tool Provider concepts, allowing compatibility without making an external Markdown schema the domain model.
