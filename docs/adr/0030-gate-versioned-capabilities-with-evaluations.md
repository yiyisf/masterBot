# Gate versioned capabilities with evaluations

Agent Revisions and material changes to Model Profiles, Context policies, Tool descriptors or Providers, Skills, and Agent Engine adapters will carry Eval Evidence before broad activation. Versioned Eval Suites separate contract, regression, capability, safety, cost, and latency goals; they prefer deterministic structural, factual, and business assertions, use controlled Tool Providers, and do not rely solely on LLM judges. Candidate changes pass static and contract checks, offline and safety evaluation, risk-based human review, then canary rollout before activation, with every result pinned to model, prompt, Tool, policy, data-set, and evaluator versions. Governed production feedback may seed reviewed, de-identified future cases.
