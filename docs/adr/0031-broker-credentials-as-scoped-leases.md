# Broker credentials as scoped leases

Connectors and other domain records will store opaque credential references, while a replaceable Credential Broker resolves them at the Tool invocation boundary into short-lived leases constrained by Organization, Principal, Connector, Tool, Invocation, allowed operations, and expiry. Agents, Harness state, events, and Artifacts never receive or persist long-lived secret values; credential resolution and use are audited without values, failures deny execution, and production adapters may target an enterprise vault while development uses an explicit local adapter. Full enterprise-vault integration is a lower implementation priority, but the reference and broker seam must exist before new Tool paths are built so plaintext assumptions do not enter contracts or data models.
