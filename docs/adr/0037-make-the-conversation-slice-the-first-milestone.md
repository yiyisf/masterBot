# Make the Employee Conversation vertical slice the first milestone

The first usable milestone will deliver one production-shaped employee flow: identity, Conversation and Message, Run creation, PostgreSQL-backed API/Worker execution, replayable SSE, provider-neutral Harness with the AI SDK Engine and model adapters, a minimal governed Tool Catalog and Runtime, approval interaction, local Artifact storage and rendering, Conversation-history context construction, baseline policy, audit, and OTel. Workflow, Runbook, RPA, full Memory and Knowledge, Skill Factory, enterprise vault integration, external policy engines, HA deployment, multiple Engines, and full evaluation administration remain later slices, although the accepted seams must not be bypassed. Acceptance requires refresh and disconnect recovery and complete Organization, Principal, audit, and trace correlation.
