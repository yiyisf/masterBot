# Isolate extension Tool Providers from the server process

Only reviewed built-in Tools shipped with the application may execute inside the main server process. Enterprise-installed or user-created executable extensions, including locally spawned MCP Providers, run through an isolated Provider host with constrained process, filesystem, network, resource, timeout, and credential access; remote Providers use the same Tool Runtime interface, and instruction-only Skills execute no code. A clearly unsafe in-process extension adapter may exist for development only. This prevents dynamically imported extension code from reading server secrets, bypassing governance, blocking or crashing the service, while allowing the initial child-process host to evolve into containers or remote execution without changing Tool contracts.
