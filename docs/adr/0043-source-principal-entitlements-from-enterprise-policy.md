# Source Principal entitlements from enterprise identity and policy systems

CMaster Bot will not build a second local per-Principal, per-Tool RBAC system. Tool Runtime still evaluates the intersection of trusted Principal entitlements, Agent Tool Grants, Invocation restrictions, Tool facts, and Policy, but the first adapter only recognizes a coarse `enterprise_assistant.use_governed_tools` entitlement provisioned by the trusted development identity; Production Starter maps trusted OIDC claims/groups, and future enterprise Policy/SCIM adapters may supply finer decisions. Agent Tool Grants remain local versioned configuration, target systems continue enforcing their own permissions, and Browser input can never assert entitlements. This keeps constrained delegation and deny-by-default governance without making CMaster the enterprise IAM or embedding business-specific role administration into the first milestone.
