# Keep Conversations private by default

A Conversation is private to its creating Principal by default, even within one Organization. All Conversation, Message, associated Run, and Employee Workspace Projection access uses trusted Organization and Principal identity; an unauthorized lookup returns the same not-found response as an unknown identity. Organization scope alone is an isolation boundary, not sharing authorization. Assistant Messages inherit the Conversation visibility boundary, while referenced Artifacts continue to enforce their own authorization independently. Future collaboration must introduce an explicit participant, sharing, or Policy decision rather than broadening existing Conversation reads implicitly; disposable prototype data and APIs require no compatibility migration.
