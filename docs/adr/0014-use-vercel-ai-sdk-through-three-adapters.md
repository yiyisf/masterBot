# Use Vercel AI SDK through three adapters

Vercel AI SDK will initially implement three independent seams: model access behind Model Gateway, the default inner tool-loop behind an Agent Engine adapter, and UI streaming behind a UI Presenter adapter. The AI SDK Agent Engine owns model/tool iteration within one Invocation, while the outer Harness retains Run and Invocation lifecycle, delegation, limits, cancellation, policy and approval, outcome handling, persistence, recovery, and audit; AI SDK Tool wrappers delegate execution to the shared Tool Runtime. AI SDK messages, tools, provider metadata, stream parts, and UI types must be normalized at these seams rather than entering domain, persistence, or public contract models, preserving replacement options while using the SDK's integrated capabilities.
