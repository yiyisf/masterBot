# Set initial Production Starter service objectives

The first profile is sized for up to 1,000 registered and 300 daily active employees, 100 simultaneous online users, 20 default and 50 configurable concurrent Runs, and 10,000 daily Runs per Organization. Interactive Runs default to ten-minute limits, background automation to two hours, Checkpoints occur at critical steps or about every thirty seconds, Output Deltas are coalesced at 50–150 ms, commands and ordinary queries target 500 ms p95 excluding external identity and model latency, and SSE replay targets two seconds p95 with at-least-once delivery, strict per-Run sequence, and client deduplication. The Starter targets 99.5% monthly availability, RPO within 24 hours, RTO within four hours, 90-day Run Events and one-year audit retention by default, with configurable and observable limits.
