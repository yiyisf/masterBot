# Model Organization ownership from the start

The initial product remains a single-Organization enterprise deployment, but Organization is an explicit data, policy, and administrative isolation scope for Conversations, Runs, Tasks, Artifacts, Agents, Tool grants, Connectors, Model Profiles, and policies. Every application command receives a trusted request context containing Organization and Principal identity, repositories scope access explicitly, and uniqueness and authorization rules include Organization where applicable. We will not build SaaS onboarding, billing, or cross-Organization operations now; carrying ownership from the beginning avoids a later destructive migration and prevents accidental cross-Organization access or content deduplication when deployment options expand.
