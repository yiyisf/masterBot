# Test through module and contract interfaces

Refactored behavior will be tested primarily through domain invariants, each module's public interface, shared adapter contract suites, production-shaped PostgreSQL integration, replayable UI projections, browser end-to-end flows, and Agent evaluations. CI runs real PostgreSQL semantics, applicable repository contracts also exercise the SQLite development adapter, and controllable clock, identity, model, Tool, and event adapters make failure and recovery deterministic. Tests that reach through a replaced module to assert obsolete internal structure are deleted once equivalent interface coverage exists; every vertical slice must prove a production-style happy path plus its critical failure modes, including SSE replay, Worker leases, Checkpoint recovery, and uncertain Tool effects.
