# Show execution transparency instead of raw reasoning

Employee UI will present structured status, user-comprehensible plans and decision summaries, redacted Tool activity, approvals, errors, and Artifacts rather than raw model chain-of-thought. Harness contracts therefore model execution facts and summaries, not a universal `thought` stream. To preserve future diagnostic capability, Engine and Model adapters may report provider-supported reasoning summaries or traces into a separate Diagnostic Trace facility that is capability-detected, disabled by default, policy-gated, encrypted, short-retained, access-audited, and available only to authorized analysis roles; it is neither a normal Run Event nor employee UI content, and the system never assumes every provider exposes it.
